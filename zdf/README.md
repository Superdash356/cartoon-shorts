# zdf: realistic 3D explainer shorts (three.js)

A second video engine next to the Remotion cartoon stories: a 9:16 "inside the object" explainer rendered frame by
frame in headless Chrome. The edit follows the voice, so a new voice take re-times every cut and caption.

| File | What |
|---|---|
| `src/shots.js` | One line: which short to render (`export * from './shorts/<slug>.js'`). |
| `src/shorts/<slug>.js` | **The edit** of each short: one function per shot, cut on voice lines/words (`L(i)`, `at(line, 'word')`). Kept: `ruby-watch`, `vinyl-deadwax`. |
| `src/shorts/<slug>.timing.js` | Generated by `python3 scripts/zdf_timing.py shorts/<slug> 40 zdf/src/shorts/<slug>.timing.js`: words, lines, captions, duration. |
| `src/vinyl.js` | Props of the vinyl short: record (grooves, dead wax, scratched code), macro groove surface, stylus, crate, attic, lathe, press. |
| `src/realhuman.js` | The realistic person: `reach` (arm IK), `aimHand`, `curl`, `look`, `lean`, `face({smile, jaw, blink, browUp...})`. |
| `src/watch.js` | Props of the test short: watch + working movement, pivot cutaway, bin, phone, tweezers. |
| `src/main.js` | Renderer, stages (`room`, `dark`, `blue`), HDR lighting, depth of field, bloom, HTML overlays. |
| `src/shots_example.js`, `human.js`, `props.js` | The original cartoon example from the skill, kept for reference (sparks, ripple, IK). |
| `fetch-assets.sh` | Downloads the person (Microsoft Rocketbox avatar, MIT) and the lighting map (Poly Haven, CC0) into `assets/` (not committed). |

## Make a short
1. Script: 9 to 10 sentences, about 105 words for 40 s. Write `shorts/<slug>/lines.json` with every `rate` at `+0%`
   (normal speaking speed; do not tighten or speed up the voice for this engine).
2. Voice: run the **Generate voice** workflow for `<slug>`, pull, then `python3 scripts/zdf_timing.py shorts/<slug> 40`.
3. Shots: edit `zdf/src/shots.js`. Check stills before any render:
   `cd zdf && npm ci && bash fetch-assets.sh && GL=swiftshader node render.mjs stills 0.2,3,8,14 /tmp/stills`
   (set `CHROME_PATH` to use an installed Chrome instead of Playwright's).
4. Render: commit, push, run **Render 3D explainer (zdf)** with `audio: shorts/<slug>/voice.wav` and a `tag`.
   20 chunks at 1080x1920; the mp4 lands in the release `<tag>` and on the `renders` branch as `<tag>.mp4`.

A different person: `bash fetch-assets.sh Adults/Female_Adult_05 f005` (folder and texture prefix from the Rocketbox repo).
